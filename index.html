QUESTIONS I'M EXPLORINGFIG. 02
  • 01 When do mistakes happen?
  • 02 How much does time trouble matter?
  • 03 How varied is the opening repertoire?
  • 04 Does playing style change by phase?

Illustrative board, not an evaluated position.

Chessonality looks for recurring patterns in games: opening choices, middlegame decisions, endgame performance, time management, and the positions where errors cluster. The longer-term goal is a useful player profile; the hard part is making those conclusions credible rather than just entertaining.

Python · Chess engines · Data analysis · Calibration

PROJECT 03 ROBOTICS / ALGORITHMS

A* in ROS 2

From a grid on paper to a path in RViz.

Learning exerciseROS 2 Jazzy / Ubuntu

Getting familiar with robotics by making path planning visible, testable, and understandable.

GRID SEARCH / SCHEMATICFIG. 03

I set up a ROS 2 Jazzy workspace, built and tested an A* node, and connected the pieces needed to display an occupancy grid in RViz. The ongoing task is connecting the planner's output to a meaningful visualization and understanding the message flow along the way.

C++ · ROS 2 · A* search · RViz
